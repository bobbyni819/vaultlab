# Security policy

## Reporting a vulnerability

If you discover a security issue in vaultlab, please report it by emailing the maintainer (see GitHub profile of `@bobbyni819`). Do **not** open a public GitHub issue for security vulnerabilities.

A maintainer will respond within 7 days and work with you to assess the issue and coordinate a fix.

## Scope

vaultlab is a research-stage open-source tool. We do not currently make formal security guarantees. Supported versions are the latest minor release.

## Out of scope

- vaultlab is **NOT HIPAA-compliant.** Do not use with PHI/PII/IRB-restricted data. See `docs/data-privacy.md` and `docs/compliance.md`.
- Issues in upstream dependencies (Anthropic SDK, scanpy, etc.) should be reported to those projects directly.
